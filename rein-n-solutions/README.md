# Rein N' Solutions — launch kit

The framework for Rein N' Solutions and Elevated Lives, extracted from the systems we built for NRT.
First use: a Fiverr storefront selling the **$300 Website + Google Business Profile + Mission Control Lite** package. The same kit works for any SMB, on or off Fiverr.

> ⚠️ **Do not merge this folder into `main` of nEXTrIGHTtHING.** This repo is public on GitHub and deploys to nextrighthing.com, so anything merged here is served on NRT's domain. Move it to a private Rein N' Solutions repo (e.g. `ElevatedLivesInc/reinnsolutions-oaas`, currently empty).

| Folder | What | Use it when |
|---|---|---|
| `design-system/` | Tokens + mapping from NRT. Full system: [artifact](https://claude.ai/artifact/SoKmuFfRcacV9qV4wySzta) | Any page, gig image, client site |
| `fiverr/01-PROFILE.md` | Seller profile, field by field | Setting up the account |
| `fiverr/02-GIG-…md` | The $300 gig: title, tags, tiers, description, FAQ, gallery | Publishing the gig |
| `fiverr/03-MESSAGE-SCRIPTS.md` | 11 Quick Responses + gig video script | Every buyer conversation |
| `fiverr/04-DAY-ONE-LAUNCH.md` | Day-one plan, targeting score, honest baseline | Launch day |
| `delivery/CLIENT-INTAKE-QUESTIONNAIRE.md` | Fiverr requirements = config fields | Order received |
| `delivery/CLIENT-GAP-INTAKE.md` | The first 6 prospects | Fill this before day one |
| `delivery/DELIVERY-SOP.md` | Hour-by-hour build, GBP checklist, Mission Control Lite spec | Fulfilling |
| `delivery/tenant-config.template.js` | The one file per client | Every build |
| `framework/SKILLS-TOOLS-PROMPTS.md` | Skills, tools, 7 prompts | Building, selling |
| `framework/AUTOMATION.md` | What runs itself, what needs a human | Setup week |
| `framework/GUARDRAILS.md` | Lines that don't move | Always |
| `framework/LICENSING.md` | Turning the kit into a product | Month 2+ |
